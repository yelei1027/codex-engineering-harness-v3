# v3.3.0 验收边界

原生 Desktop 未验证项按用户明确决定作为已知限制保留。原生 Codex Desktop 审批、工具调用与 Hook 信任不可由 CLI、SDK 或静态配置替代；本版本保持未验证。

各版本实测和当前 3.3.0 包验证记录在 docs/RELEASE-3.3.0.md，不将历史结果当作新版执行结果。取消为尽力语义，不能撤销已提交操作；网络故障时不保证远端工作立即停止。第三方 Provider 的基本截图生成已在隔离候选实测，但该次未观察到工具执行；Replicate/Gemini 附加能力须分别配置和验证。

发行包需要在线重建锁定依赖，网络和 Docker 子网容量可阻止准备。所有准备失败保留日志、数据与受管进度。旧项目仍绑定原安装；活动项目延后迁移。卸载/测试回收保留数据卷、环境文件及恢复记录。未知配置与资源不会按名称猜测删除。

最终候选曾有一次模拟依赖准备测试提前退出；12 次隔离诊断未复现，后续正常全量及公共验收通过。原始失败记录保留，原因未查明；不把重复通过当作该异常原因已解决。
